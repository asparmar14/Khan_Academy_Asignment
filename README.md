# Khan Academy Analytics Assignment

## 📌 Overview
This project builds a data pipeline and reporting system to track student reading fluency across schools.

## ⚙️ Tech Stack
- Python (pandas, sqlite3)
- SQLite (local database)
- Jupyter Notebook

## 📂 Project Structure
```
Khan_Academy_Repo/
│── notebook.ipynb
│── README.md
│── requirements.txt
│── data/
│── outputs/
```

## 🚀 How to Run
1. Place JSON files inside `/data`
2. Open notebook
3. Run all cells
4. Outputs will be generated in `/outputs`

## 📊 Outputs
- school_tracker.csv
- SCH_134065_report.csv
- SCH_134141_report.csv

## 🧠 Key Insights
- Latest attempt used for accurate performance tracking
- WCPM used as core fluency metric
- Identified low-performing students for intervention
